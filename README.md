# Encryption-Decryption-Python_Project-
A simple Python tool for encrypting and decrypting messages using the Fernet module from the cryptography library. It securely generates, stores, and uses a key to protect user input, ensuring both confidentiality and integrity of the data.

🔐 Encryption & Decryption in Python
Here we explore basic cryptography using Fernet:
<br>🗝️ Generate & store secure keys (secret.key)
<br>📥 Encrypt user input with symmetric encryption
<br>📤 Decrypt ciphertext with integrity check (MAC)
<br>💾 File handling for key reuse
<br>🧪 Match original & decrypted messages
<br>📦 Uses cryptography library (Fernet)
<br>🚫 Handles missing dependencies gracefully
<br>📌 Emphasis on confidentiality & integrity
